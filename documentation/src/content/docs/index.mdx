Welcome to Knurl! A desktop HTTP client for testing APIs with a focus on simplicity, security, and local-first storage.

## What is Knurl?

Knurl is a native desktop application that lets you:
- Build and execute HTTP requests
- Organize requests into collections
- Manage environments and variables
- Test APIs with multiple authentication methods
- Analyze responses with built-in tools

Everything stays on your machine. No cloud sync, no telemetry.

![Knurl Workspace Overview](/screenshots/01-workspace-overview.png)

## Key Features

### Collections
Organize your API requests into hierarchical collections with folders. Every collection is stored locally with optional per-collection encryption.

### Request Builder
Create requests with full HTTP support, custom headers, query parameters, and multiple body formats (raw, JSON, form-encoded, multipart).

### Authentication
Built-in support for:
- Basic Authentication
- Bearer Tokens
- API Keys
- OAuth 2.0 (client credentials, authorization code, device code flows)

### Environments & Variables
Define named environments with variables that automatically interpolate into your requests—URLs, headers, bodies, and authentication.

### Response Analysis
View responses with formatted JSON display, raw payload inspection, and request/response metadata including timings and headers.
