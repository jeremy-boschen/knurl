## What is Knurl?

Knurl is a desktop HTTP client for testing and debugging APIs, similar to Postman. You can create HTTP requests, organize them into collections, manage different environments, and analyze responses—all locally on your computer.

## Installation

Download Knurl from [the releases page](https://github.com/newty/knurl/releases) for your operating system (macOS, Windows, or Linux).

## Your First Request

1. **Open Knurl** - Launch the application
2. **Click the "+" button** in the left sidebar to create a new request
3. **Enter a URL** at the top (example: `https://httpbin.org/get`)
4. **Click Send** (or press Ctrl+Enter / Cmd+Enter)
5. **See the response** in the right panel

That's it! You've made your first request with Knurl.

## The Main Interface

- **Left Sidebar**: Your collections and requests (organized by folder)
- **Top**: Request URL and send button
- **Tabs**: Params, Headers, Body, Authentication, Options for configuring your request
- **Right Panel**: Response data, headers, cookies, and logs
