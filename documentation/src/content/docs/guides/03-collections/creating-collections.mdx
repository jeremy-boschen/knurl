## What is a Collection?

A collection is a container for organizing your API requests. Think of it like a project folder.

**Example collections**:
- "Customer API" - all requests for the customer service API
- "Payment Service" - all requests for billing and payments
- "Internal Tools" - internal API requests

## Creating a Collection

1. In the left sidebar, click the **"+" button** next to "Collections"
2. Give it a name (example: "GitHub API")
3. Done! Now you can add requests to it

## Organizing with Folders

Inside a collection, you can create folders to organize requests by feature or endpoint.

**In the left sidebar**:
1. Right-click your collection
2. Select "New Folder"
3. Name it (example: "Users" or "Authentication")
4. Create subfolders if needed

**Example structure**:
```
GitHub API
├── Users
│   ├── Get User
│   ├── Update User
│   └── Delete User
├── Repos
│   ├── List Repos
│   ├── Create Repo
│   └── Delete Repo
└── Issues
    ├── List Issues
    ├── Create Issue
    └── Close Issue
```

## Managing Collections

### Rename
Right-click a collection → **Rename**

### Delete
Right-click a collection → **Delete**

(This also deletes all requests in the collection)

### Reorder
Drag collections in the sidebar to change their order

### Move Requests
In the sidebar, drag a request between folders or collections

## Collection Settings

Right-click a collection → **Collection Settings**

Here you can configure:
- **Default Environment**: Which environment applies to all requests in this collection by default
- **Default Authentication**: Shared authentication (API key, bearer token, etc.) for all requests

Individual requests can override these defaults.

## Best Practices

- **One collection per API**: Create separate collections for different services
- **Use folders for organization**: Group related requests (Users, Posts, Comments)
- **Descriptive names**: Use clear names like "Create User" instead of "POST 1"
- **Keep collections focused**: Don't mix unrelated APIs in one collection
- **Share collections**: Export collections to share with teammates or save for future reference
