## Exporting Collections

Export your collections to:
- Back them up
- Share with teammates
- Version control them (commit to Git)
- Migrate to another computer

**To export**:
1. Right-click a collection in the sidebar
2. Select **Export**
3. Choose a location and filename
4. Your collection is saved as a file

## Importing Collections

Import collections that you've exported or received from teammates.

**To import**:
1. In the sidebar, click the **menu icon** next to Collections
2. Select **Import Collection**
3. Choose the file you want to import
4. The collection is added to your Knurl

## Merging Imported Collections

If you import a collection that has the same name as an existing one, Knurl will:
- Ask if you want to merge or create a separate copy
- **Merge**: Combine with existing collection (adds new requests, overwrites duplicates)
- **New Copy**: Keep both with different names

This is useful for:
- Updating collections from teammates
- Combining multiple versions
- Keeping a backup while merging changes

## Sharing Collections

**Option 1: Direct file**
- Export your collection
- Send the file to teammates
- They import it into their Knurl

**Option 2: Version control (Git)**
- Knurl collections are stored locally
- You can backup individual collections and commit them to your repo
- Teammates can import them

## Tips

- **Regular backups**: Export important collections regularly
- **Share with team**: Exported collections make great starting points for new team members
- **Version your API specs**: As APIs change, version your collection exports
