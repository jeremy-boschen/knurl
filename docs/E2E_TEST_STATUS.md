## Test Status Legend

- ✅ PASS: All tests passed
- ❌ FAIL: Some or all tests failed (shows count)
- ⏳ NOT RUN: Test file not yet executed
- ⚠️ UNKNOWN: Results unclear or incomplete data

## How to Update This Document

Run the status tracker script to refresh results from JSON files:

```bash
python3 scripts/parse-e2e-results.py
```

This reads test results from `test-results/*.json` files generated by WebDriver.io and updates the status.

## Test Results Location

JSON results are stored in: `test-results/results-*.json`

Each file contains detailed test pass/fail information in WebDriver.io's native JSON format.

## Notes

- Tests are run individually to identify specific failures
- Status is updated as each test completes
- See `test/specs/` for test implementations
- To run all E2E tests: `yarn test:e2e`
- To run specific test: `yarn test:e2e --spec="test/specs/auth.e2e.ts"`
