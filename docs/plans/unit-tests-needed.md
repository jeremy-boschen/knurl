# Unit Tests Needed

Tests that should be **unit tests** (not E2E) because they test business logic/behavior that isn't exposed via the UI or can't be verified visually.

## Format
- **Test Name:** Name of the behavior being tested
- **Current Location:** Where it's currently attempted as E2E
- **Rationale:** Why this is unit test material
- **Suggested Implementation:** Brief notes on how to test this in isolation
